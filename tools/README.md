# Research utilities

| Tool | Role |
|---|---|
| `build_theory.py` | Compile canonical LaTeX and capture source/PDF hashes |
| `catalog_research.py` | Read-only inventory of configured experiment records |
| `verify_theory_algebra.py` | Selected symbolic identities, not physical validation |
| `import_shared_conversation.py` | Private acquisition of supplied discussion |
| `audit_imported_discussion.py` | Audit saved one-interface data; not a dynamics rerun |
| `execute_notebooks.py` | Execute source notebooks into artifacts |
| `verify_emitter_notebook.py` | Reproduced emitter-equilibrium metrics and offline embedded pressure-wave playback checks |
| `verify_emitter_formation_notebook.py` | Unforced surfaces/spot image and saved-state surface/spot playback checks |
| `verify_dual_notebook.py` | Offline browser playback and pause checks for the two-face pressure animation |
| `verify_formation_notebook.py` | Offline synchronization checks for the single-face surface, error and spot animation |
| `verify_dual_setup.py` | Both-interface selection and camera-only rotation checks in the combined notebook |
| `summarize_maintenance.py` | Earlier single-interface campaign summary |
| `verify_viewer.py`, `verify_stationary_viewer.py` | Browser behavior checks |

Numerical experiment entry points live with their declared Python model, not
in miscellaneous standalone scripts. No utility publishes data or adds a remote.
