# Studies

Each study asks one scientific question. [STATUS.md](../STATUS.md) gives the
reviewed verdicts, and [ledger.json](ledger.json) records nine separate evidence
states for the representative runs. [run-index.json](run-index.json) inventories
preserved report files with hashes; presence in that inventory does not
establish success. Rebuild the index and status page with
`python3 tools/documents/build_research_index.py`.

| Study | Question |
|---|---|
| [S01](S01-single-interface/study.md) | Can the earlier single-interface model form and recover at fixed drive? |
| [S02](S02-independent-two-face/study.md) | Do independent two-face fits survive fixed-command refinement? |
| [S03](S03-stigmatic-target-ideal-load/study.md) | What load forms a shared-conjugate pair before asking whether sound can supply it? |
| [S04](S04-emitter-synthesis/study.md) | Can the idealized finite source array supply the required load? |
| [S05](S05-emitter-formation/study.md) | Does the saved emitter command form the target in the declared Stokes model? |
| [S06](S06-two-face-physical-checks/study.md) | Is a converged two-interface emitter state robust, stable and reachable? |
| [S07](S07-faithful-modal-synthesis/study.md) | Can a low-order modal source correct the acoustics-off meniscus to a faithful, reachable two-face target? |
| [S08](S08-published-singlet/study.md) | Can the apparatus be adapted so a published stigmatic singlet (Silva-Lora and Torres Fig. 9b) is formed faithfully? |
| [S09](S09-universal-source/study.md) | Which stigmatic singlets can one fixed machine (cell, liquids, source layout) form, and which extra source freedom helps most? |

Historical reports and configurations remain intact as execution evidence.
Their numerical claims are scoped to their own models and protocols.
Detailed links into `artifacts/studies/` require the separate local research
data tree; the GitHub repository contains the reviewed study summaries.
